# Ticket Management System

This is a simple ticket management system built using Streamlit, SQLite, and Python. The system allows you to add, view, delete, and upload traffic tickets. It also supports sending email notifications and exporting ticket data to Excel.

## Features

- **Add Ticket**: Allows you to manually input ticket information, including uploading images.
- **Bulk Upload**: Upload multiple tickets from an Excel file.
- **View Tickets**: View all tickets stored in the database, with the option to delete or export them to Excel.
- **Send Notifications**: Send email notifications regarding ticket milestones.

## Requirements

Before running the app, you need to install the required dependencies. You can do so by running:

pip install -r requirements.txt
